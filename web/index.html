PACT 浏览器入口

三个单文件页面，覆盖从“写下第一份域声明”到“接到 agent”的完整路径。全部离线运行，不联网、不上传。

第一步 · 写域
写域

域作者工作台：六个形状配方、内嵌分析器与作者契约，浏览器内跑与 pact analyze 同源的检查。
第二步 · 跑一遍
跑一遍

运行沙盒：以不同参与者身份 seed / produce / read / consume，实时看 Counter、Archive 与 Rule-T。
第三步 · 接到 agent
接到 agent

接入向导：按本机 stdio 或远程 HTTP 生成 pact.toml、MCP 客户端配置与启动命令。
三个页面均为单文件、无外部资源、无网络请求；也可下载仓库后直接双击打开。 第三方页面可嵌入任一页面：<iframe src="…/index.html?embed=1"> 只保留内容区与状态胶囊。 源码与命令行实现：github.com/onlookor/pact-collab
